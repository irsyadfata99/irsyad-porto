# Portfolio — Irsyad Fata Al Aidi

Backend-focused developer portfolio built with React + Vite + Tailwind CSS.

## Getting started

```bash
npm install
npm run dev       # local dev server
npm run build     # production build -> dist/
```

## Structure

- `src/data/content.js` — all copy: profile, projects, experience, skills, certificates. Edit this file to update content without touching components.
- `src/components/` — Hero, Projects, Experience, Skills, Contact, Nav.
- `tailwind.config.js` — design tokens (colors, fonts).
